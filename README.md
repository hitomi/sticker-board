# 贴贴 · Sticker Studio

React + TypeScript + Vite + Tailwind CSS + Fabric.js 的纯前端贴纸工作台。

## 本地运行

```sh
npm install
npm run dev
```

打开终端显示的地址。开发服务器监听所有网卡，同一局域网的手机可以访问电脑 IP 的 5173 端口。

```sh
npm run check
npm run build
npm run preview
```

`dist/` 可部署到任意静态托管服务，支持部署在子目录。Node.js 使用支持 Vite 8 的版本（20.19+ 或 22.12+）。

## 功能

- 首次打开自动使用当前设备尺寸（屏幕尺寸 × 像素比估算），并提供常用手机、平板、电脑、正方形和自定义尺寸。最长边超过 4096 px 时按比例缩小并明确提示；浏览器缩放和系统显示设置可能影响估算值。设备方向变化会更新尺寸选项，不会覆盖正在编辑的画布。
- ZIP 导入 PNG、JPG、WebP、GIF、SVG、AVIF。目录路径保留为分类标签；忽略隐藏文件和 macOS 元数据。
- 贴纸拖动、缩放、旋转、水平/垂直翻转、复制、图层顺序、删除。点击画布外空白取消选中；悬浮工具栏不参与画布布局。
- 支持拖框、Shift 点选、全选及手机点选多选模式。多选作为整体移动、缩放、旋转、翻转，可批量复制、删除和调整图层；Ctrl/Cmd+A 全选，Escape 取消选中。
- “我的上传”分类支持单张或批量上传图片，导入新 ZIP 不会清空个人素材。
- 最近 35 个状态的撤销和重做；支持 Ctrl/Cmd+Z、Shift+Ctrl/Cmd+Z、Ctrl/Cmd+D 和 Delete。
- 纯色、自定义颜色、透明背景或上传背景图片；图片居中铺满并随画布尺寸适配，替换和移除支持撤销。按原始画布分辨率下载 PNG。
- 桌面侧栏，手机底部抽屉；自带 12 张本地矢量示例贴纸。
- 设置：站点标题、Logo／favicon、主题色直接更新当前页面，自定义主题色可选择亮色或暗色文字。
- 导出独立版：直接打包当前设置、完整贴纸库（含个人上传）、画布尺寸、背景和已摆放的贴纸，生成可离线打开或静态部署的 `index.html`，不需要重新上传 ZIP。导出弹窗分别设置是否允许上传图片（贴纸与背景）和 ZIP 素材，默认关闭。
- 恢复配置：从导出的 ZIP 或 `index.html` 读取配置，校验通过并确认后替换当前工作区。仅解析内嵌 JSON，不执行导入页面的脚本；兼容之前仅包含贴纸和品牌设置的旧独立文件。
- 重置：清空全部素材（包含示例贴纸）、画布和历史，恢复默认外观；清空结果也会保存到浏览器。
- 本地持久化：IndexedDB 自动保存设置、图片素材、背景和当前画布。刷新、关闭后重新打开会自动恢复；撤销历史只在当前会话内保留。

界面隐藏滚动条，贴纸库和抽屉仍可滚动；禁用界面文字选择，输入框保留文字编辑能力。

文件只在浏览器本地处理，不上传服务器。当前工作区保存在本浏览器的 IndexedDB 中，不跨设备同步。保存失败会提示并提供重试；本地存储无法读取时可重试或进入不会覆盖旧数据的临时模式。清理网站数据或无痕会话结束可能移除本地数据，导出文件可用作备份。GIF 等动画格式作为静态贴纸导出。单个素材 ZIP 限制 100 MB，解压后图片总量限制 200 MB，单张图片限制 3200 万像素；直接上传的图片每张限制 20 MB，一批限制 100 MB；大素材包仍可能受设备可用内存限制。

## 独立版构建

`npm run runtime` 使用同一套应用代码，以 `__STANDALONE__` 编译开关构建单文件模板到 `public/standalone.html`。`npm run dev` 启动前和 `npm run build` 会自动更新模板。开发期间修改编辑器代码后，运行 `npm run runtime` 更新用于导出的模板。

用户导出时把版本化配置及当前素材和画布写入模板的 JSON 数据块，所有图片均内嵌，界面和编辑逻辑与主应用一致。普通构建和独立版模板都必须更新后再部署。每次导出的独立版拥有独立存储标识，避免重新发布时被旧浏览器草稿覆盖。配置恢复文件上限为 400 MB。
